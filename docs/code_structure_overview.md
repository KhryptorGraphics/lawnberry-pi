## Agent bridge (developer tooling)

`tools/agent_bridge/` is the approval-gated, GitHub-issue-driven local coding-agent worker (OhMyPi `omp` primary,
Claude Code `claude` alternative). It is developer tooling for a workstation: it is never deployed to the mower or
the base station and imports nothing from `backend/`. Run it from the repository root with
`python -m tools.agent_bridge`. Design: `docs/agent-bridge.md`; operation: `docs/agent-bridge-operations.md`;
issue format: `docs/agent-bridge-task-template.md`. Signatures below are copied from the source; `self` is omitted.

| Path | Purpose | Subsystem | Callable interfaces |
|---|---|---|---|
| `tools/__init__.py` | Marks `tools/` as the developer-tooling package (docstring only). | Developer tooling | none. |
